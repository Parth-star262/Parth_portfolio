# Parth Hada — Personal Portfolio Website

A personal developer portfolio built with Next.js, Tailwind CSS, and Framer Motion.

## 🚀 Features
- **Hero Section**: Bio, education (IIIT Vadodara '28), 500+ DSA stats, resume download, and social links.
- **Flagship Project**: Showcase for [DSA-Judge](https://dsa-judge.vercel.app).
- **Technical Skills**: Categorized skills matrix (Languages, Frontend, Backend, DevOps & AI) with continuous marquee ticker.
- **Background**: Academic journey, campus roles (Finance Club, E-Cell), and milestones.
- **Interactive Contact**: One-click email copy & pre-filled contact form.

---

## 🛠️ Local Development

```bash
# 1. Install dependencies
npm install

# 2. Run local dev server
npm run dev
```

Visit `http://localhost:3000`.

---

## 📦 How to Push to a New GitHub Repository

```bash
# 1. Initialize git in this portfolio folder
git init

# 2. Add and commit all files
git add .
git commit -m "feat: initial commit for personal developer portfolio"

# 3. Create a new repository on GitHub named 'portfolio'
# 4. Link and push to your new repo:
git remote add origin https://github.com/Parth-star262/portfolio.git
git branch -M main
git push -u origin main
```

---

## 🌐 Deploy to Vercel (1-Click)
1. Go to [vercel.com/new](https://vercel.com/new).
2. Select your newly created `portfolio` GitHub repository.
3. Click **Deploy**.
